05 // VELOCIDAD AL VOLANTE

Atajos Esenciales de Omarchy

La tecla Super es la tecla Windows/Cmd de tu teclado.

Lanzadores
Menú de Apps: Super + Espacio
Terminal: Super + Enter
Navegador: Super + Shift + B
Archivos: Super + Shift + F
Ventanas
Cerrar Ventana: Super + W
Pantalla Completa: Super + F
Flotante / Mosaico: Super + T
Cambiar División: Super + J
Sistema
Espacios (1..9): Super + [1..9]
Menú Apagar / Lock: Super + ESC
Portapapeles: Super + Ctrl + V
Guía Completa: Super + K
